🗺️ Visão Geral Sistema

O FireRisk combina três fontes de dados independentes para montar um perfil de risco de incêndio para qualquer coordenada dentro da Amazônia Legal. Cada coletor é responsável por um domínio específico:

Coletor 1
🌡️ Climate
Temperatura, chuva e vento dos últimos 30 dias via Open-Meteo
Coletor 2
🛰️ FIRMS
Focos de incêndio ativos detectados pelo satélite VIIRS/Suomi NPP (NASA)
Coletor 3
🌿 Vegetation
Município, UF e bioma de qualquer ponto via IBGE GeoJSON
Ponto de entrada único: src/main.py → coletar_dados(lat, lon) orquestra os três coletores e retorna um dicionário consolidado com todos os dados.

🌡️ Climate Open-Meteo

API: api.open-meteo.com/v1/forecast  ·  Gratuita, sem chave

Retorna um DataFrame pandas com 31 linhas (hoje + últimos 30 dias). Cada linha representa um dia completo de dados climáticos para a coordenada informada.

Coluna

Precipitação acumulada no dia
unidade: mm
Coluna

Velocidade máxima do vento
unidade: km/h

NaN em precipitation: ocorre quando a API ainda não tem o valor processado para o dia atual. Trate com df["precipitation"].fillna(0) ou descarte a linha mais recente.

Como usar

from collectors.Climate import Climate

c = Climate()
df = c.get_data(lat=-3.1190, lon=-60.0217)

# temperatura média dos últimos 30 dias
print(df["temperature_max"].mean())

# dias sem chuva (risco de seca)
dias_secos = (df["precipitation"] == 0).sum()
print(f"Dias sem chuva: {dias_secos}")

🛰️ FIRMS NASA

API: firms.modaps.eosdis.nasa.gov/api/area/csv  ·  Chave gratuita: NASA_FIRMS_KEY

Retorna um DataFrame pandas com todos os focos de incêndio detectados pelo satélite VIIRS/Suomi NPP na Amazônia Legal nos últimos N dias. Cada linha é um foco individual.

Área de cobertura fixa — Amazônia Legal

Bounding box: longitude -74° a -44° · latitude -18° a 5° — cobre AM, PA, MT, RO, AC, RR, AP, MA e parte do TO.

Como usar

from collectors.Firms import Firms

f = Firms()                        # lê NASA_FIRMS_KEY do ambiente
df = f.get_focos(dias=7)

# apenas focos com alta confiança
df_alto = df[df["confidence"] == "h"]

# focos com FRP > 100 MW (grandes incêndios)

🌿 Vegetation IBGE

APIs: servicodados.ibge.gov.br  ·  Gratuitas, sem chave

O coletor de vegetação faz três coisas distintas: baixa o mapa vetorial dos municípios brasileiros, identifica o município de uma coordenada e classifica o bioma. Internamente usa GeoPandas para operações espaciais.

Métodos e o que retornam

Método
download()
Baixa o GeoJSON dos ~5570 municípios do Brasil e salva em data/raw/municipios.geojson
retorna: None (salva arquivo)
Método
read_geo_data()
Lê o GeoJSON local e enriquece com nome e UF via API IBGE
retorna: GeoDataFrame
Método
get_municipio(gdf, lat, lon)
Dado um GDF e uma coordenada, retorna o município que contém o ponto
retorna: dict ou None
Método
get_bioma(uf)
Dado a sigla da UF, retorna o bioma predominante
retorna: string

Atenção: o mapeamento UF → bioma é uma aproximação. Estados como MT e MA têm áreas em múltiplos biomas. Para precisão fina, é necessário um shapefile de biomas do IBGE.

Como usar

from collectors.Vegetation import Vegetation

veg = Vegetation()

# baixar GeoJSON apenas na primeira vez
# veg.download()

gdf        = veg.read_geo_data()
municipio  = veg.get_municipio(gdf, lat=-3.1190, lon=-60.0217)
bioma      = veg.get_bioma(municipio["uf"])

print(municipio)  # {'codarea': '1302603', 'nome': 'Manaus', 'uf': 'AM'}
print(bioma)      # Amazônia

⚙️ main.py Orquestrador

A função coletar_dados(lat, lon) é o ponto de entrada único. Ela instancia os três coletores, executa o pipeline completo e devolve um dicionário com tudo consolidado.

Fluxo de execução

1
Vegetation.read_geo_data()

Lê o GeoJSON local e faz merge com a API de nomes do IBGE. Operação mais lenta (~5–15 s na primeira execução com internet).

2
Vegetation.get_municipio(gdf, lat, lon)

Testa ponto-em-polígono para todos os ~5570 municípios. Retorna None se o ponto cair no oceano ou fora do Brasil.

3
Vegetation.get_bioma(municipio["uf"])

Lookup imediato no dicionário interno. Sem requisição.

4
Climate.get_data(lat, lon)

Requisição para Open-Meteo. Retorna 31 linhas de dados diários.

5
Firms.get_focos(dias=5)

Requisição para NASA FIRMS. Quantidade de linhas depende da atividade de incêndios no período.

Usando o retorno em código

import sys
sys.path.insert(0, "src")

from main import coletar_dados

dados = coletar_dados(lat=-3.1190, lon=-60.0217, dias_focos=7)

# município identificado
print(dados["municipio"]["nome"])     # Manaus
print(dados["bioma"])                  # Amazônia

# quantos dias sem chuva?
df = dados["clima"]
print((df["precipitation"] == 0).sum())

# focos de alta confiança e alto FRP
focos = dados["focos"]
criticos = focos[(focos["confidence"] == "h") & (focos["frp"] > 50)]
print(f"Focos críticos: {len(criticos)}")
